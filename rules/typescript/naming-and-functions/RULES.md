# 이름과 함수

- 의미 있는 이름: 변수나 함수 이름은 길더라도 서술적이고 명확한 단어를 사용합니다.
- 작은 함수: 함수의 인자는 3개 이하로 유지합니다. 프레임워크가 인자의 수와 순서를 정한 함수만 예외입니다. 인자가 3개를 넘는 함수는 하는 일을 나눕니다. 인자의 수를 줄이려고 인자들을 새 객체 타입으로 묶지 않습니다. 받은 값을 그대로 객체로 돌려주는 함수는 만들지 않고, 값이 필요한 자리에 객체를 직접 적습니다. 다른 모듈이 객체를 직접 적어야 하는 타입은 그 타입을 선언한 모듈이 내보냅니다.
- 작은 단위: 코드는 읽기 좋은 잘 쓴 글처럼 직관적이어야 합니다.
- 삼항 연산자: 삼항 연산자는 두 값 가운데 하나를 고를 때만 씁니다. 삼항 연산자 안에 삼항 연산자를 다시 쓰지 않습니다. 조건이 둘 이상이면 함수로 빼고, `if` 문 안에서 바로 `return` 합니다.
